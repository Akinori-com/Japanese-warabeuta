# 🐻 くまさん くまさん まねっこ＆ことばあそび アプリ

特別支援学校（知的障害）小学部の国語科単元向けに開発されたWebアプリケーション教材です。
電子黒板やプロジェクター、タブレット（iPad等）、PCのブラウザで手軽にお使いいただけます。

---

## 🎯 単元のねらい

1. **言語を聞いて、その動作を真似すること（模倣・身体表現・指示理解）**
   - わらべ歌「くまさん くまさん」の親しみやすいリズムと先生の歌・声かけに合わせて、くまさんのイラストを手がかりに身体を動かす楽しさを味わいます。
2. **該当する部分を別の言葉に置き換えて、他の動作を誘発するような言葉を考えること（語彙の拡張・創造的表現）**
   - 「くまさん くまさん ○○○」の○○○の部分を児童と一緒に考え、「ジャンプして」「バンザイして」など、言葉が変わることでみんなの動きも変わる面白さを体験します。

---

## 🚀 使い方・起動方法

### ① 起動する
- フォルダ内の **`index.html`** をダブルクリックするだけで、通常のWebブラウザ（Google Chrome, Microsoft Edge, Safari等）で起動します。
- **完全オフライン対応**：インターネット接続がない教室環境でも動作します。

### ② 基本の操作
- **「つぎへ ▶」「◀ まえへ」ボタン**：カードを順番に切り替えます（キーボードの矢印キーやスペースキーでも可能）。
- **画面のくまさんをタッチ**：くまさんがもう一度ピョンと動きます（「もう1回やってみよう！」という声かけの時に便利です）。
- **「⛶ 全画面」ボタン**：電子黒板いっぱいに大画面表示できます。
- **「じどうでおくる」スイッチ**：ONにすると5秒ごとに自動で次の動作に進みます。先生が電子黒板の前を離れて児童と一緒に身体を動かしたい時に活用できます。

---

## 📋 主な機能

### 1. うたうカードをえらぶ（カード選択・並び替え）
- 右上の「📋 カードをえらぶ」ボタンから、授業で使用するカードを自由に選べます。
- **基本の4つ（まわれみぎ、りょうてをついて、かたあしあげて、さようなら）**にワンクリックでリセット可能。
- プリセットとして、児童が身体を動かしやすい15種類の動作（あしぶみ、ジャンプ、拍手、バンザイ、あたまポンポン、深呼吸、お辞儀、しゃがむ、せのび、おしりふりふり、ストップ、おやすみなさいなど）が用意されています。
- 「▲」「▼」ボタンで歌う順番を自由に並び替えることができます。

### 2. あたらしいことばをつくる（自由登録機能）
- 右上の「✏️ ことばをつくる」ボタンから、児童の発案したオリジナル動作を追加できます。
- **入力項目**:
  - うしろのことば（例：「うでをぐるぐる」「たかくジャンプ」など）
  - くまさんのポーズ選択、**または写真・イラスト画像（アルバムアプリやカメラから選択可能）**
- **写真の自動軽量化**: 高画質写真も自動で適切なサイズ（約50KB）にリサイズ・圧縮されるため、端末の容量を圧迫せずスムーズに動きます。
- **自動保存＆バックアップ機能**:
  - つくったカードはこの端末（ブラウザ）に**自動でずっと保存**されます。
  - 「📋 カードをえらぶ」画面の **「💾 カードをファイルに保存」** を使うと、カードデータをファイルとして書き出せます。
  - **「📂 ファイルから読みこみ」** を使えば、学校の別のiPadや電子黒板に簡単にカードセットを移行できます。

## 🏫 特別支援教育（UD）における配慮ポイント

- **見やすい大きな文字・分かち書き**:
  遠くの席からでもはっきり読める特大フォントと、単語を区切った分かち書きを採用しています。
- **刺激を抑えたやさしい配色**:
  真っ白ではなく温かみのあるクリームイエローの背景色にし、視覚過敏の児童にも配慮しています。
- **大きなタップ領域**:
  電子黒板のタッチパネルやタブレットの指先操作でも押し間違えにくい、大きめのボタン設計です。
- **あたたかい声かけを重視した無音設計**:
  機械的な合成音声ではなく、先生自身の歌声や掛け声、児童同士のやり取りを主役にできるよう、アプリ側からの突然の過剰な音響刺激をあえて排しています。
